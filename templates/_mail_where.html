{# Open a Mail draft on the Mac the person is actually sitting at. The app runs on the hub, so mail_draft.create_draft opens Mail on the hub -- useless when Larry is travelling, which is most of the reason the tailnet exists. See claude/ops/29-where-mail-drafts-open.md. The browser is the way across. It is served by the hub but it is running on THIS Mac, so it can pull the message from the hub and hand it to a small local service (tools/draft_helper.py, 127.0.0.1:5055). The message crosses as data and becomes a real editable draft here. Progressive enhancement, deliberately: the page asks whether the helper is there and only then offers the local button. With no helper it degrades to exactly what it did before -- the hub button and the .eml download -- so a Mac that has not been set up is never left with a dead control. Included by the statement screen and the welcome-email screen. Both must set `eml_url` first; `mail_host` is the server's own hostname. #}

{# The no-helper state. Also what every Mac sees before the ping returns. #}
Where the draft opens. “Open draft” runs Mail on {{ mail_host }} — the Mac running this app, which is not necessarily the one you are sitting at. If you are browsing the portal from another Mac, the window opens over there and nothing appears here. {% if not mail_available %} Apple Mail was not found on {{ mail_host }}, so that button is off entirely. {% endif %}
Download .eml works from any Mac: it is the complete message. Open it, then Message ▸ Send Again (⇧⌘D) to turn it into a sendable copy — Mail shows an .eml as a received message until you do.
To get a real draft on this Mac instead, install the draft helper once: run tools/install_draft_helper.command from the app folder. This page picks it up on its own afterwards.
