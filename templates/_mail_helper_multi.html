The Pipeline shows every open lead at once, so that partial cannot be included per card -- duplicated ids would leave one card driving another's button. This is the same mechanism with the state moved onto the buttons themselves. Each button carries: data-eml -- where to fetch the built message from the hub data-stage -- where to POST the stage change once Mail really has it The buttons start hidden and are revealed only if the helper answers, so a Mac that has not been set up sees Download .eml and nothing broken. #}
